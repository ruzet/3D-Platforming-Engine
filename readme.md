# 3D Platforming Engine

This is a 3D Platforming Engine made for Hack Club's Terra!
You can download it and import it into Godot and probably build off of it or smth iono
You can test it out over here! (https://ruzet.itch.io/3d-platformer-engine)!

## How

I made this with Godot, the engine i've been using through out most of Terra, and I really just coded stuff until it worked how I wanted to, nothing interesting to really say here. I also made music for the game which is kinda cool i think.

## Features

* Dashing
* Bonking ([NULLSCAPE](https://nullscape.wiki/Main_Page) Inspired)
* Skidding
* Sliding (slope affected)

## Player Colors

* Green - Dashing
* Red - Bonked
* Yellow - Sliding
* Yellow-Green - Skidding
* Light Blue / Dark Blue - Max Air Jumps / No Air Jumps

## Testing

* The platformer test builds have been tested for Mac, but not tested for Windows (tested on Crossover)
* For any Terra reviewer that read's this, Try the Mac build first!
* **You will most likely have to allow the game to run through Settings -> Privacy & Security on Mac**

## Controls

* WASD - Move
* Space - Jump
* E/Shift (Ground/In Air) - Slide/Dash
* C/Ctrl - Crouch
